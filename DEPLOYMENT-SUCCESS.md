## 🎯 Cara User Menggunakan:

### **1. Install Fresh (Dengan Auto-Prompt)**
```bash
# Clone & install
git clone https://github.com/meteoradja-ytmjk/ozanglive
cd ozanglive
bash install.sh

# Saat muncul prompt: "Setup domain sekarang?"
# - Ketik Y → Setup domain langsung
# - Ketik N → Skip, dapat panduan lengkap
```

### **2. User yang Sudah Install, Mau Setup Domain**
```bash
# Download installer domain
cd ~
curl -fsSL https://raw.githubusercontent.com/meteoradja-ytmjk/ozanglive/main/ozanglive-universal-multidomain-quick-installer-v2.sh -o domain-setup.sh
chmod +x domain-setup.sh
bash domain-setup.sh
```

### **3. Akses Dokumentasi**
```bash
# Interactive menu
bash ~/ozanglive/docs-menu.sh

# Quick reference
curl -fsSL https://raw.githubusercontent.com/meteoradja-ytmjk/ozanglive/main/SETUP-DOMAIN-QUICKSTART.txt

# Full guide
curl -fsSL https://raw.githubusercontent.com/meteoradja-ytmjk/ozanglive/main/CARA-SETUP-DOMAIN.md
```
