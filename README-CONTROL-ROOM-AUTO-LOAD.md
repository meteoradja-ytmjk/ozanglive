# 🚀 Control Room - Auto-Load Stream Key (README)

## 📌 What's New?

**Stream key sekarang otomatis ter-load saat kamu pilih YouTube channel di Control Room!** 🎉

Tidak perlu lagi:
- ❌ Copy-paste stream key manual
- ❌ Klik dropdown 2 kali
- ❌ Cari-cari stream key di YouTube Studio

**Cukup:**
- ✅ Pilih channel → Stream key ready!
- ✅ Klik "Start Stream" → Done!

---

## ⚡ How to Use

### Step 1: Open Control Room
Klik tab **"Control Room"** di dashboard

### Step 2: Create New Stream
Klik tombol **"+ New Stream"** (hijau)

### Step 3: Select YouTube Account
Pilih YouTube channel dari dropdown

### Step 4: ✨ Magic Happens!
Stream key **otomatis ter-load** - kamu akan lihat:
- ✅ Green checkmark: "✓ Stream key loaded"
- ✅ Toast notification: "Auto-loaded stream key"
- ✅ Dropdown sudah ter-select

### Step 5: Start Streaming
Pilih video, isi title, klik **"Start Stream"** → DONE! 🎊

## 🆘 Troubleshooting

### Stream key tidak auto-load?
1. **Refresh page:** Ctrl + Shift + R (hard refresh)
2. **Check connection:** Pastikan YouTube account masih connected
3. **Check console:** F12 → Console → lihat error messages

### Dropdown kosong?
1. **Create stream key di YouTube:** Buka YouTube Studio → Go Live
2. **Or select "Create new":** System akan buat stream key baru otomatis

### Masih bermasalah?
1. Clear browser cache
2. Logout → Login lagi
3. Reconnect YouTube account
4. Contact support dengan screenshot error

## 💡 Tips

### Tip 1: Multiple Stream Keys
Kalau punya banyak stream keys:
- Yang pertama akan auto-load
- Bisa ganti dengan klik dropdown dan pilih yang lain

### Tip 2: Manual Mode
Masih bisa pakai manual mode:
- Pilih "-- Manual Stream Key --"
- Paste stream key sendiri

### Tip 3: Multiple Accounts
Punya banyak YouTube channels:
- Pilih channel A → stream key A loaded
- Pilih channel B → stream key B loaded
- Smooth switching! 🔄
